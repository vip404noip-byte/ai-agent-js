作業 3：建立迷你知識庫

任務描述：
使用課程教的向量資料庫，建立一個小型知識庫並測試搜尋功能。

---

主題選項： 
台灣城市介紹（台北、台中、高雄等 5 個城市的特色）  

---

步驟指引：

15. 參考課程的 Embeddings 和向量資料庫程式碼  
16. 建立知識庫的初始化程式，準備5筆知識內容  
17. 執行程式將知識加入向量資料庫  
18. 建立搜尋測試程式  
19. 用 3 種不同問法搜尋，檢驗結果相關性

---

應交內容：

- Embeddings 相關程式 
- 向量資料庫操作程式  
- 知識庫初始化程式  
- 搜尋測試程式

---

驗收標準：

- 知識庫包含 5 筆以上資料  
- 執行搜尋測試程式能搜尋到相關結果
