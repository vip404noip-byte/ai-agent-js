作業 2：新增一個 Function Calling 工具
==================================================

任務描述：
參考課程的天氣工具，新增加一個「計算機」工具，讓 AI 可以進行數學運算。

為什麼要新增計算機？
- 不需要寫外部 API，可以更快速理解 Function Calling 流程
- 邏輯簡單，容易驗證結果是否正確
- 能清楚理解工具的定義和呼叫流程

步驟指引：
7. 建立計算機工具檔案

8. 定義工具的 JSON Schema：
   - name: `calculate`
   - description: 進行數學計算
   - parameters: `expression`（字串，如 `"10 + 5 * 2"`）

9. 實作計算函數（可用 `eval()` 或自行解析）  
10. 在工具註冊中心註冊工具  
11. 測試 AI 能否正確呼叫計算機  

繳交內容：
- 計算機工具（含 JSON Schema 定義和動作）
- 工具註冊程式
- 聊天管理程式
- 主程式

檢核重點：
- [ ] 計算機工具包含完整的工具定義與動作
- [ ] JSON Schema 定義正確（type、function、parameters）
- [ ] AI 能夠在對話中正確呼叫計算機（截圖證明）
- [ ] 計算結果正確
